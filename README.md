# odin-etch-a-sketch

* This is a web adaptation of the classic etch-A-sketch game. The default grid will be made of 16x16 grid 256 squares in all.
* Additional features, hover mouse effect so that the grid changes colors when your mouse passes over them (leaving pixelated trail)
* Button at the top of the screen that prompts user asking number of squares per side for new grid. Once entered the existing grid should be removed and new grid should be generated. (Max number set to 100)
* Randomize squares RGB values with each interaction.
* Implement a progressive darkening effect, each interaction should darken the square by 10%. Turn the square completely one color in 10 interactions.
